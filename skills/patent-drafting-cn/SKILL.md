# 中国发明专利申请材料转换技能（阶段 B）

## 激活条件
默认研发工作流停止于 skills/patent-technical-brief/SKILL.md 的工程技术方案书。**先检查用户明确申请决定、锁定的 08a_technical_brief.json，以及 MCP patent_conversion_status 的 conversion_authorized=true**。任何条件不满足，返回待审批状态，不生成正式申请底稿。

## 输入
经过工程负责人复核的单一方案、技术事实、合法现有技术原文及来源锚点、测试证据、企业申请策略与可信审批记录。必须区分“许可转换申请稿”和“许可提交申请”。

## 程序
1. 读取固定版本 external/patent-disclosure-skill 和当前有效中国法规。
2. 从白话技术事实中识别技术问题、必要特征、结构/控制协同关系、可替代实施方式、参数范围和相应证据。
3. 与技术负责人确认独立权利要求保护边界，展开从属权利要求、技术领域、背景技术、发明内容、附图说明、具体实施方式、摘要。
4. 使用现有 patent-figure-cad 对 STEP/CAD/示意图做正式申请用途的黑白线稿审核。
5. 使用 patent_draft_save 保存 08_application.json；生成 claim_support 矩阵，逐特征核对披露基础、术语、部件号与图号。联系企业专利管理人员和代理机构进行提交前复核。

## 门禁
只接受经过可信审批服务签名、绑定案卷/运行/候选/方案哈希且未过期的转换许可。AI 或普通 MCP 工具不能生成批准签名。正式申请提交、专利授权及法律结论均不可由 AI 自动声称。失败则停留阶段 A，标注差异和待补资料。
