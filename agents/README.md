# 专利研发多智能体目录（简体中文）

本目录定义企业级专利研发的 13 个专业角色。它们是当前 ChatGPT/Codex 对话内的任务角色；宿主支持真实多 Agent 时可分别分派，不依赖额外模型 API。Python 仅承担检索、证据和校验等确定性工具。

每个角色明确输入、输出、独立审查和失败交接。统一使用证据 ID（EV-...）、论文 DOI、专利公开号和案卷版本，不将未经核实的 AI 内容当作事实。

| 编号 | 智能体 | 主要职责 |
|---|---|---|
| 01 | [总控编排智能体](01-coordinator.md) | 接收用户的一句话任务，维护研发案卷与阶段推进，分派专利、论文、创新、工程和撰写任务。 |
| 02 | [保密与权限智能体](02-confidentiality.md) | 识别未公开发明、CAD、BOM、客户项目和内部报告的敏感级别，核查对外检索与调用授权。 |
| 03 | [全球专利检索智能体](03-patent-search.md) | 通过具备权限的数据源检索中国与全球专利、完整权利要求、同族和引证。 |
| 04 | [学术论文检索智能体](04-paper-search.md) | 检索 OpenAlex、Crossref、arXiv 和合法开放获取论文，提取科学原理与跨领域技术机会。 |
| 05 | [技术路线与知识关联智能体](05-landscape.md) | 融合专利和论文证据，形成技术矛盾、已公开方法、失效机制和可研究空白。 |
| 06 | [多路线创新智能体](06-inventor.md) | 独立采用 TRIZ、SCAMPER、设计思维、FMEA 和跨行业迁移生成可实现的机械与控制发明构思。 |
| 07 | [现有技术反证智能体](07-adversarial.md) | 独立寻找能够否定候选方案新颖性或创造性的专利和论文证据。 |
| 08 | [机械工程论证智能体](08-engineering.md) | 检验各候选发明在力、热、流体、机构、控制、制造和安全方面的理论可实施性。 |
| 09 | [发明保护布局智能体](09-portfolio.md) | 识别核心发明特征、可选改型和潜在同族保护主题，制定中国发明专利权利要求布局。 |
| 10 | [中文发明专利撰写智能体](10-drafter.md) | 调用已固定版本的中国专利 Skills 完成交底书、独立与从属权利要求、说明书、摘要和附图说明。 |
| 11 | [机械专利附图智能体](11-figures.md) | 将真实 STEP/SolidWorks 结构模型转成黑白结构线稿，并对标号、引线、图幅进行质量检查。 |
| 12 | [专利质量复核智能体](12-quality.md) | 执行新颖性/创造性、充分公开、实施例支持、引用真实性及保密权属的独立复核。 |
| 13 | [企业案卷治理智能体](13-governance.md) | 维护案卷状态、访问权限、来源追踪、审计记录、成本和业务级 SLA 报告。 |

## 调度与独立性
总控编排完成阶段状态与保密授权管理；专利检索与论文检索平行；技术路线/创新可并行；反证与工程校核须由独立角色完成；专利审查与最终申请人审批须由真实专业人员执行。
若当前 AI 客户端不具备并行子 Agent，就按上述顺序通过角色隔离和独立记录模拟多个审查岗位，明确其独立性局限。
完整路线详见 ../docs/ENTERPRISE_BLUEPRINT.md。
